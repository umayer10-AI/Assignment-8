# 🐄 QurbaniHat

## 📌 Project Overview
QurbaniHat is a modern livestock booking platform built with **Next.js**.  
It helps users easily browse, select, and book healthy animals for Qurbani with a smooth and user-friendly experience. The platform includes authentication, sorting, booking system, and profile management.

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/umayer10-AI/Qurbani-Hub.git
```

### 2. Navigate to the Project Folder

```bash
cd qurbanihat
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create a `.env.local` File

```env
MONGODB_URI=your_mongodb_connection_string

BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=http://localhost:3000

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

### 5. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## ✨ Key Features

- 🔐 User Authentication (Email & Google Login) using Better Auth
- 🐄 Browse all available animals for Qurbani
- 🔎 Sort animals by price (Low → High, High → Low)
- 📄 Detailed animal information page
- 🛒 Booking form for animals
- 👤 User profile page with update functionality
- 🖼️ Responsive UI with modern design (Tailwind + HeroUI)
- ⚡ Fast performance using Next.js App Router
- 🔒 Protected routes for profile and animal details
- 🎯 Toast notifications for actions (login, booking, etc.)
